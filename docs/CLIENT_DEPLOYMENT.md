# 顧客展開チェックリスト

新しい顧客に Olive Note を展開するときの **作業フロー** です。

> 想定: あなたが作業して、引き渡し後は顧客の管理者が運用する。

---

## ⏱ 全体フロー（標準60分）

| 時間  | 作業 | 担当 |
|------|------|------|
| 0:00 | 顧客から導入情報をヒアリング | あなた + 顧客 |
| 0:05 | 顧客のGoogle Cloudプロジェクト作成 | あなた（顧客代行 or 顧客自身） |
| 0:15 | OAuth Client ID 発行             | あなた |
| 0:25 | Drive SA 発行 & フォルダ準備     | あなた |
| 0:35 | (任意) Vertex AI セットアップ     | あなた |
| 0:40 | 顧客サーバーで MySQL DB 作成     | あなた + 顧客 |
| 0:45 | ZIPアップロード & インストーラ実行 | あなた |
| 0:55 | 動作確認 & 引き渡し               | あなた + 顧客 |

---

## ✅ ヒアリング項目

顧客にこれだけ最初に聞いておく：

```
1. 使うドメイン:    ___________________________
   (新規ドメイン取得が必要なら 1〜2日前倒し)

2. SSL証明書 (Let's Encrypt等で OK):  □ 設定済み  □ 要設定

3. レンタルサーバー: ___________________________
   (Xサーバー / さくら / ConoHa など。PHP 8.0+ 必須)

4. メンバー予定人数:  ____名

5. 初期管理者:
   - 氏名:        ___________________________
   - メール:      ___________________________
   - Gアカウント所有:  □ あり / □ 要作成

6. Google Workspace 使用有無:  □ 有  □ 無
   (有 の場合は OAuth 同意画面を「内部」にできる)

7. 想定する利用開始日:   _________
```

---

## 🛠 顧客側ですべきこと（事前準備）

顧客に事前にお願いするのは以下のみ：

1. **メンバーの Google アカウント一覧** （氏名 + メール）
2. **既存ファイルの整理** （Drive上に整理したいフォルダ構造）
3. **HTTPS化されたドメイン**

これだけ用意してもらえれば、あとはあなたの作業で完結します。

---

## 📦 デプロイ手順（短縮版）

詳しくは [INSTALL_GUIDE.md](./INSTALL_GUIDE.md) 参照。

### A. Google Cloud 側

1. [OAUTH_SETUP.md](./OAUTH_SETUP.md) — Client ID 発行
2. [DRIVE_SETUP.md](./DRIVE_SETUP.md) — SA & 3フォルダ準備
3. (任意) [VERTEX_SETUP.md](./VERTEX_SETUP.md) — Vertex AI 設定

### B. サーバー側

1. DBを作成
2. 最新の `olivenote-X.Y.Z.zip` を `public_html/olivenote/` に展開
3. ブラウザで `https://example.com/olivenote/` にアクセス → ウィザード
4. 5ステップ入力 → セットアップ完了

### C. 動作確認

| チェック項目 | OK? |
|------|:---:|
| Googleログインできる | □ |
| 課題を新規作成できる | □ |
| 添付ファイルがDriveに上がる | □ |
| ドキュメント画面で新規作成できる | □ |
| 設定画面で他メンバーを追加できる | □ |
| カレンダー / ガント / ボード すべて表示 | □ |
| 通知が届く | □ |
| (任意) AI機能が動く | □ |
| アップデート画面が「最新版です」と表示 | □ |

## 📬 引き渡し時に伝えること

メール or 引き渡し資料に：

```
✉️ Olive Note 導入完了のお知らせ

アクセス先:
  https://example.com/olivenote/

初期管理者:
  ○○@example.com (○○ 様)

主な操作方法:
  - ヘッダー右下の💬「AIコンシェルジュ」に質問するのが一番早いです
  - 詳細マニュアルは別途配布

定期メンテナンス:
  - DBバックアップは自動で5世代保持されます (data/backups/)
  - システムのアップデートは「設定 → システムアップデート」から実行できます
    （管理者のみ表示。所要1〜3分）

サポート連絡先:
  ○○@your-company.com
```

## 💼 引き渡し後の保守

| 頻度 | 作業 |
|---|---|
| 必要時 | 新バージョン公開時にあなたがリリース → 顧客はボタン1つで更新 |
| 月1   | 顧客サーバーの `data/backups/` を別ストレージに退避（バックアップの保険） |
| 半年  | OAuth 同意画面 / SA キーの確認（Googleの仕様変更追従） |
| 緊急時 | バックアップから手動復旧（[UPDATE_GUIDE.md](./UPDATE_GUIDE.md) 参照） |
